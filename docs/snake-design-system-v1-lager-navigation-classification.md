# Lager-pilot: navigasjonsklassifisering

Denne klassifiseringen låser informasjonsarkitekturen før Lager kobles til
Snake Design System v1.

## Global navigasjon

- Dashboard
- Lager
- Viper
- Konto og samlet administrasjon
- Dato og klokkeslett

Global navigasjon svarer bare på hvor brukeren er i Snake OS.

## Lokal modulnavigasjon

- Oversikt
- Produkter
- Lokasjoner
- Ryddemodus
- Avvik
- Telling
- Aktivitet

Dette er stabile arbeidsområder i Lager. De skal ikke gjentas som permanente
valg i sideinnholdet.

## Tabs for visninger

- Produkter: Alle, Mangler, Har sone, Har lokasjon og Avvik
- Avvik: Alle, Kritisk, Sjekk og Info
- Aktivitet: Alle og hendelsestyper

Tabs endrer visningen av samme datasett. De navigerer ikke mellom
arbeidsområder.

## Toolbar for handlinger og filtre

- Produkter: søk, Shopify-synk, collection-filter, sonefilter og massevalg
- Lokasjoner: søk, sonefilter, ny lokasjon og skriv ut etiketter
- Avvik: søk og produkt-/lokasjonsfilter
- Aktivitet: oppdater
- Telling: lokasjonssøk
- Ryddemodus: lokasjonssøk, lagre og hopp over

Toolbars inneholder bare handlinger eller filtre som påvirker den aktuelle
arbeidsflaten.

## Innhold som ikke er navigasjon

- Lager-oversiktens arbeidskort og anbefalinger
- Systempuls, statuskort, metrikker og fremdrift
- Produkt-, lokasjons-, avviks- og aktivitetslister
- Hurtigvalg i Ryddemodus som kontekstuelle lenker
- Tilbake-lenker på detalj- og etikettflater
- Dialoger og skjemaer

Arbeidskort kan fortsatt lenke til et arbeidsområde som en kontekstuell
anbefaling, men de er ikke en tredje navigasjonsrad.
